## 2. Verification Guidelines

1. **Grounded Source**: Every quantitative metric or performance claim must refer to a specific test log or version-controlled evidence file.
2. **Context Bounding**: Public wording must explicitly restrict the claim to the testing environment (e.g. `im Pilotlauf`, `in der Testumgebung`).
3. **No Unbounded Guarantees**: Remove all absolute qualitative or quantitative guarantees.
4. **Evidence Hash Integrity**: The SHA-256 hash of the evidence file must be recorded in this register.
